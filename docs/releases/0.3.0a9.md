# torch-coral 0.3.0a9

Experimental integration for the first-generation Coral USB Edge TPU.

- Static PyTorch-to-TFLite compilation, extended operator rewrites and reusable
  direct-runtime buffers.
- Experimental Qwen3.5-0.8B text execution through the INT8 matrix array and FP32
  scalar instructions, including Turbo V2/V3/V4 profiles.
- Turbo V4 Alpha 9: prepared asynchronous USB dispatch, shared quantization,
  fused normalization/activation/selection and verified speculative decoding.
- Coral Studio: separate settings, live token/s and prefill/decode visualization.

Download the wheel and install it in a suitable Python environment:

```sh
python -m pip install ./torch_coral-0.3.0a9-py3-none-any.whl
```

For the optional chat interface, use the downloaded wheel with the `chat` extra:

```sh
python -m pip install './torch_coral-0.3.0a9-py3-none-any.whl[chat]'
coral-qwen-chat
```

The runtime tier supports Python 3.9+; the PyTorch frontend and experimental chat
stack require Python 3.12+. The pure-Python wheel does not bundle USB drivers,
Google runtimes, the Edge TPU compiler, tinycoral, models or tokenizers. Set up
the isolated worker and external components as documented in the repository.
The chat GUI supports the documented Qwen text graph; arbitrary Hugging Face
models are not guaranteed to compile or execute. Interactive decoding remains
experimental and slow; short or repetitive benchmarks are not general chat rates.

The release workflow checks package metadata, audits every wheel member for
private files and credentials, and checks imports/CLI in an isolated environment.
`SHA256SUMS` records the uploaded wheel's SHA256. No PyPI upload is performed.
